Features

专为开发者与运维打造的趁手利器

告别在终端、浏览器、聊天窗口之间来回复制代码的低效工作流。

自研内置 Shell

彻底摆脱 Windows PowerShell 的语法怪癖与回显污染。内置 ls, cat, grep, find, du, df, head, tail 等 30+ 核心命令，各平台操作习惯高度一致。

单窗口原生沉浸

没有多余的侧边栏抽屉，没有聊天对话泡泡。AI 的分析思考作为注释行呈现，自动生成的命令像真实手工输入一样留在当前行，保持终端纯粹。

高危命令双重门禁

规则黑名单 + 模型智能审查。凡涉及 rm -rf、服务重启、磁盘格式化等敏感操作，强制行内二次确认（支持 y 执行、N 放弃、e 现场改写）。

SSH 远程运维深度优化

启动即选主机列表，多服务器快速切入；支持私钥与保存密码认证。内置 sudo / su 交互式接管机制，杜绝远端卡死与无回显隐患。

按使用度智能 Tab 补全

记录个人真实输入频次，越常用的命令排在越前面。空输入时直接按 Tab 摊开常用命令推荐；参数智能匹配，多候选补齐最长公共前缀。

单文件免安装分发

基于 Node 官方 Single Executable Application (SEA) 打包，生成独立的 Windows (mono.exe)、macOS 及 Linux 二进制，随身 U 盘即插即用。

Quick Start

三步即刻开启 AI 运维

1

下载单文件或 npm 全局安装

支持 Windows / Linux / macOS。免环境依赖直接运行：

npm install -g monoshell 或在下方下载单文件
2

运行向导配置大模型 Key

支持 OpenAI、DeepSeek、Claude、Ollama 或任意兼容 OpenAI 协议的本地大模型：

ai setup 交互式一步步引导问答
3

输入 ai 开启沉浸会话

选择本地或远程服务器连接，进去后随便敲命令或直接用中文下达运维任务：

ai 启动连接挑选器
